# 📋 ClipSync

Простой онлайн-буфер обмена: кидаешь текст с телефона — забираешь на ПК (и наоборот).

## Как это работает

1. Открываешь сайт на телефоне, вводишь текст → получаешь 4-значный код.
2. На ПК заходишь по коду или по ссылке → текст уже там.
3. Текст синхронизируется в реальном времени — правки видны на обоих устройствах.

## Стек

- Чистый HTML / CSS / JS (без сборщиков)
- Firebase Realtime Database
- Хостинг: GitHub Pages

## Локальный запуск

1. Клонируй репу
2. Открой в VS Code → установи расширение **Live Server**
3. Правый клик по `index.html` → **Open with Live Server**

## Firebase

Нужен свой проект Firebase. Конфиг — в `js/firebase.js`.
